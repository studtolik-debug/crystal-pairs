# Игра на Android

Три пути, от самого быстрого к самому «настоящему».

---

## 1. Поиграть прямо сейчас (ничего не устанавливать)

На компьютере, в папке игры:

```bash
python -m http.server 8080 --bind 0.0.0.0
```

Телефон должен быть в той же Wi-Fi сети. Открыть в Chrome:

```
http://192.168.1.125:8080/index.html
```

(адрес компьютера в сети; если он изменится — посмотреть `ipconfig`)

Рекорды сохранятся в браузере телефона для этого адреса. Минус: игра живёт,
только пока компьютер включён, а при смене IP рекорды не переедут.

---

## 2. Установить как приложение (PWA) — без APK и без Android-инструментов

Открыть игру на телефоне (см. пункт 1) → меню Chrome (три точки) →
**«Установить приложение»** / «Добавить на главный экран».

Появится иконка с бриллиантом, игра запустится на весь экран без адресной
строки. Рекорды хранятся в хранилище приложения и живут до удаления или
очистки данных.

Чтобы работало **офлайн и без компьютера**, файлы нужно положить на любой
бесплатный HTTPS-хостинг (например, GitHub Pages) — service worker
(`sw.js`) включается только на HTTPS и после первой загрузки кэширует игру
целиком. По локальной сети (http://) офлайн-режим не включится.

---

## 3. Настоящий APK — Capacitor

Игра целиком упакуется внутрь приложения: работает офлайн, хостинг не нужен,
рекорды лежат в приватном хранилище приложения и стираются только при
удалении игры или очистке её данных. Это точно то поведение, которое нужно.

### Что поставить один раз

| Что | Зачем | Где взять |
|---|---|---|
| **JDK 17** | сборка Android | Temurin / Microsoft OpenJDK |
| **Android SDK** | платформа и build-tools | Android Studio либо `commandlinetools` |

Затем задать переменные окружения `JAVA_HOME` и `ANDROID_HOME`
(`ANDROID_HOME` обычно `C:\Users\<вы>\AppData\Local\Android\Sdk`).

Проверка, что всё встало:

```bash
java -version
```

### Сборка

```bash
npm install
```

```bash
npm run android:add
```

```bash
npm run android:apk
```

Готовый файл появится здесь:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Его можно скинуть на телефон и установить (нужно разрешить установку из
неизвестных источников). Для публикации в Play Store нужен release-вариант с
подписью — это отдельный шаг.

### После правок игры

`index.html` в корне — единственный источник правды. Перед пересборкой
`npm run android:apk` сам перекладывает файлы в `www/` скриптом
`build-www.js`, так что копии не разъезжаются.

Папка `android/` в git не хранится. Правки нативного кода лежат в
`native/android/` по тем же путям (сейчас это `MainActivity.java`: игра
во весь экран, без строки состояния и панели навигации). Скрипт
`apply-native.js` накладывает их после `cap sync`, его зовут
`android:add`, `android:sync` и `android:apk`.

Если менялись файлы, а телефон показывает старую версию — поднять версию
кэша в `sw.js` (строка `const CACHE = "gems-v1"`).

---

## Где именно лежат рекорды

Игра пишет их в `localStorage` браузера/WebView под ключами
`gemMergeHistory` (последние 10 партий) и `gemMergeBest` (лучший результат).

| Путь | Что стирает рекорды |
|---|---|
| По сети (п. 1) | очистка данных Chrome, смена адреса компьютера |
| PWA (п. 2) | удаление приложения, очистка данных Chrome |
| APK (п. 3) | удаление игры, «Очистить данные» в настройках приложения |

Обновление приложения рекорды **не** трогает.

Если браузер запретит хранилище (бывает в приватных окнах и при открытии
файла напрямую через `file://`), игра не сломается: в панели рекордов
появится красная строка о том, что список живёт только до перезагрузки.
